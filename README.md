## 🌟 Projetos em Destaque

### 📦 [VSRepository](https://www.npmjs.com/package/vsrepo)
> Uma biblioteca open source inspirada no **JpaRepository**, projetada para simplificar a camada de persistência com Prisma através de métodos inferidos.

- **Diferenciais**: Type Inference automático, Métodos dinâmicos, Segurança, Praticidade.
- **Exemplo**: `userRepository.findByEmail(email);`

### 🧑‍💼 [EmpreGo](https://www.emprego-vagas.com.br)
> Plataforma completa para divulgação e recomendação inteligente de vagas de emprego (Em desenvolvimento).

- **Stack**: Node.js, TypeScript, React, PostgreSQL, Redis, Socket.IO, Azure.

### 🏢 [HAPS Engenharia](https://www.hapsengenharia.com.br)
> Portal institucional para empresa de engenharia.

- **Stack**: React, Node.js, Tailwind CSS, EmailJS.
